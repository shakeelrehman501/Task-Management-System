## Task Management System
A full-stack Task Management System built with React.js, Node.js, Express.js, and MongoDB. 
Users can register, log in and manage their tasks through a simple interface.

## Features
- User Registration
- User Login
- User Logout
- Create Task
- Edit Task
- Delete Task
- View user tasks
- Update Task status

## Backend
- Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt


### Frontend

- React.js
- React Router
- Axios
